Deploy manual en Lambda (handler.js legible + node_modules)
==========================================================

1) Instalar dependencias solo para esta carpeta (desde la raíz del repo):

   npm install --prefix lambda --omit=dev

   (o: cd lambda && npm install --omit=dev)

2) Crear un .zip con el contenido de la carpeta lambda/ que incluya:
   - index.js (entrada por defecto de Lambda)
   - handler.js
   - package.json
   - carpeta node_modules/ completa

   En Windows (PowerShell), desde la carpeta lambda:

   Compress-Archive -Path index.js,handler.js,package.json,node_modules -DestinationPath ..\lambda.zip

   En bash:

   cd lambda && zip -r ../lambda.zip index.js handler.js package.json node_modules

3) En AWS Lambda:
   - Runtime: Node.js 20.x (o 22; evita mezclar handler con otro runtime)
   - Handler: index.handler   ← coincide con el archivo index.js y export handler
     (alternativa válida: handler.handler si subís solo handler.js como entrada)
   - Subir lambda.zip
   - Variables de entorno (mínimo): CONTENTFUL_SPACE_ID, CONTENTFUL_ACCESS_TOKEN
   - Opcional: CONTENTFUL_ENVIRONMENT, CONTENTFUL_TESTIMONIAL_CONTENT_TYPE,
     CONTENTFUL_LOCALE
   - CORS: si el front está en otro dominio (ej. CloudFront), definí
     CORS_ORIGIN=https://xxxx.cloudfront.net (sin barra final; varios separados por coma)
   - Si la URL pública incluye stage y/o prefijo (ej.
     .../default/landing-back/health) y Express devuelve 404, definí:
     API_GATEWAY_STAGE=default
     API_BASE_PATH=landing-back
     (sin slashes; el orden importa: primero stage, luego base)

4) Delante: API Gateway HTTP API con integración Lambda proxy (ANY / y ANY /{proxy+}).
